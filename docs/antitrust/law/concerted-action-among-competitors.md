# Concerted Action Among Competitors (Restraints of Trade)

This section organizes the Section 1 framework for horizontal restraints: when competitor coordination is analyzed under the rule of reason, when it is treated as per se unlawful, and when courts use an abbreviated rule of reason.

## Place in the Framework

Concerted action among competitors generally begins with the threshold question whether there is an agreement, combination, or conspiracy. Once concerted action is established, the next question is which mode of analysis applies.
