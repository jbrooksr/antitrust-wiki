# Per Se Analysis

Per se analysis applies to categories of restraints that courts treat as almost always anticompetitive and lacking redeeming competitive virtue.

## Place in the Framework

Per se rules conserve judicial resources and provide clear notice, but modern doctrine is careful about applying them outside established categories.
